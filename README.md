# Minsk Transfer Tours Bot

Telegram-бот для подбора попутчиков в мини-группы до 4 человек и управления заявками.

## Бронирование и уведомления

- Для оформления заявки турист указывает имя и номер телефона/контакт.
- Email не запрашивается и не используется.
- Подтверждения и обновления отправляются через Telegram.
- Если турист недоступен в Telegram, организатор связывается с ним по указанному номеру телефона или WhatsApp вручную.

## Управление организатора

При открытии бота администратор с Telegram ID, указанным в `ADMIN_ID` в `main.py`, получает административное меню. Туристы видят обычное меню маршрутов.

В панели организатора доступны:
- группы и участники;
- новые заявки;
- расписание и изменение времени;
- добавление дат поездок;
- просмотр контактных данных участников;
- отмена заявки с освобождением мест и пересчётом стоимости;
- изменение количества мест в конкретной заявке.

При изменении состава группы бот пересчитывает цену по тарифам `route_prices` и уведомляет участников через Telegram. Контакты других туристов участникам группы не раскрываются.

## Сценарий группы

Первый турист предлагает дату и предварительное время начала. Каждая новая инициированная туристом группа создаётся отдельной записью, даже если на этот маршрут и дату уже есть другая группа. Организатор может скорректировать время. Группы, в которых отменены все заявки и которые были созданы туристами, скрываются из публичного списка.

## Запуск на Render

Build command: `pip install -r requirements.txt`

Start command: `gunicorn --bind 0.0.0.0:$PORT main:app`
