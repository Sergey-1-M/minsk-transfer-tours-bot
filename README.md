# Minsk Transfer Tours Bot

Telegram-бот для подбора попутчиков в мини-группы до 4 человек.

## Обновление базы данных для Email

Перед запуском версии с Email откройте Supabase → SQL Editor и выполните содержимое файла
`supabase_migration_email.sql`. Миграция добавляет поле `email` в таблицу `bookings`.

## Настройка отправки писем в Render

Добавьте в Environment следующие переменные SMTP-сервиса:

- `SMTP_HOST` — адрес SMTP-сервера.
- `SMTP_PORT` — обычно `587` для STARTTLS или `465` для SSL.
- `SMTP_USER` — логин почтового ящика.
- `SMTP_PASSWORD` — пароль или пароль приложения.
- `FROM_EMAIL` — адрес отправителя (если не задан, используется `SMTP_USER`).

Без SMTP-переменных бот продолжит принимать заявки и отправлять Telegram-сообщения, но письма отправляться не будут. После настройки проверьте доставку тестовым бронированием.

## Сценарий группы

Первый турист предлагает дату и предварительное время начала. Каждая новая инициированная группа создаётся отдельной записью, даже если на этот маршрут и дату уже есть другая группа. Организатор может изменить время через панель `/admin` → «Расписание» → «Изменить время». Участники активных заявок получают уведомления.

## Запуск на Render

Build command: `pip install -r requirements.txt`

Start command: `gunicorn --bind 0.0.0.0:$PORT main:app`
